## 2. Product Wedge Strategic Decision (Select One)

```
[ ] KEEP

    core architecture and expand pilot cohort to 5–10 paying contractors.

[ ] DEEPEN
    The wedge is validated, but needs deeper granular sub-breakdowns (e.g. sub-zoning
    volume sheets or direct MK sign-off tracking).

[ ] MODIFY
    The problem is valid, but the user interface or terminology requires structural
    adjustment to match contractor daily habits.

[ ] PIVOT
    An adjacent problem (e.g. Subcontractor Commitments or Direct Project Cash) repeatedly
    dominated customer urgency over Progress-to-Cash.
```

## 4. Threshold for Proceeding to Commercial Cohort

The founder should proceed with commercial expansion of the Progress-to-Cash wedge if:
- $\ge 3$ Real contractors complete onboarding successfully;
- $\ge 2$ Show verifiable independent repeat usage without founder prompts;
- $\ge 2$ Execute real Actions resolving economic exposures;
- $\ge 2$ Request paid continuation for multiple projects;
- Zero systematic doubts exist regarding mathematical accuracy and tenant security.
