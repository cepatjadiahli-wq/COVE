# COVE — Pilot Customer 13-Point Qualification Form

> **Purpose**: Formal qualification gate executed by the founder before issuing a pilot invitation.  
> **Rule**: Do NOT pilot any contractor solely because they agreed to view a demo. Ensure high problem-fit and operational commitment.

---

## 1. The 13 Qualification Questions

```
┌────┬───────────────────────────────────────────────────────────────────────┬─────────┐
│ #  │ Qualification Criterion                                               │ Yes/No  │
├────┼───────────────────────────────────────────────────────────────────────┼─────────┤
│ 01 │ Apakah kontraktor memiliki minimal 1 proyek aktif yang sedang jalan?  │ [ ] Y/N │
│ 02 │ Apakah proyek menggunakan metode progress billing / termin bulanan?   │ [ ] Y/N │
│ 03 │ Apakah nilai klaim termin material (> Rp 100 Juta per termin)?        │ [ ] Y/N │
│ 04 │ Apakah ada alur opname fisik lapangan $\rightarrow$ BAP konsultan MK? │ [ ] Y/N │
│ 05 │ Apakah visibilitas termin saat ini terfragmentasi (Excel/WhatsApp)?   │ [ ] Y/N │
│ 06 │ Apakah ada kendala termin/piutang riil yang sedang dihadapi saat ini? │ [ ] Y/N │
│ 07 │ Apakah ada Commercial Manager / Lead QS yang ditugaskan sebagai PIC?  │ [ ] Y/N │
│ 08 │ Apakah tim Keuangan / Billing bersedia dilibatkan untuk data invoice? │ [ ] Y/N │
│ 09 │ Apakah kontraktor bersedia memasukkan data 1 proyek aktif ke COVE?    │ [ ] Y/N │
│ 10 │ Apakah kontraktor dapat menyediakan data 3–10 klaim historis/terkini? │ [ ] Y/N │
│ 11 │ Apakah tim kontraktor bersedia hadir pada 4 sesi review mingguan?     │ [ ] Y/N │
│ 12 │ Apakah ada akses langsung ke Direktur / Owner selaku pengambil dana?  │ [ ] Y/N │
│ 13 │ Apakah profil kontraktor selaras secara strategis dengan ICP COVE?    │ [ ] Y/N │
└────┴───────────────────────────────────────────────────────────────────────┴─────────┘
```

---

## 2. Qualification Decision Matrix

```text
TOTAL "YES" RESPONSES: [____] / 13

[ ] ACCEPT (12 – 13 "Yes")
    Prospect qualifies with high conviction. Issue Pilot Invitation and schedule 
    onboarding session within 48 hours.

[ ] ACCEPT_WITH_CONDITIONS (10 – 11 "Yes")
    Prospect qualifies, but requires clear agreement on missing conditions 
    (e.g. securing formal Finance participation or confirming weekly sync attendance).

[ ] DEFER (7 – 9 "Yes")
    Insufficient problem severity or active project availability. Place in nurture 
    sequence and review in 60 days.

[ ] REJECT (< 7 "Yes")
    Mismatched ICP (e.g. micro-renovator, software seeker with no active projects, 
    or turnkey contractor with no interim opname). Politely decline.
```
