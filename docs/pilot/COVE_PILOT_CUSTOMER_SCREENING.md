# COVE — Pilot Customer Screening & Qualification Guide

> **Objective**: Filter and select the top 3–5 contractor candidates with the highest probability of providing meaningful operational feedback, executing real commercial actions, and validating the Progress-to-Cash wedge.

---

## 1. Ideal Customer Profile (ICP)

| Attribute | Ideal Pilot Customer Profile |
| :--- | :--- |
| **Business Entity** | Indonesian General Contractor (PT / CV), B2B Commercial, Infrastructure, or Industrial |
| **Company Size** | Growing Small to Mid-Market (Rp 15B – Rp 250B annual project portfolio) |
| **Active Projects** | 2 to 8 concurrent active projects |
| **Billing Model** | Progress billing / Termin bulanan / Milestone progress (NOT 100% turnkey lump-sum without interim opname) |
| **Organization Structure** | Distinct QS / Commercial function + dedicated Finance / Project Admin |
| **Executive Proximity** | Owner / Managing Director remains actively involved in monthly cash flow & billing reviews |
| **Current Tooling** | Fragmented spreadsheets (Excel, Google Sheets), WhatsApp groups, and generic accounting software (Accurate, Zahir, Jurnal) |
| **Current Pain** | Experiencing billing delays, uncertified volume disputes with MK, or overdue invoices |
| **Pilot Willingness** | Willing to assign 1 active project and 2–3 team members for 30 days |

---

## 2. Anti-Profiles (DO NOT PRIORITIZE)

* **Micro Residential Builders / Tukang Harian**: Single-house renovators with no formal opname, BAP, or progress claim documentation.
* **Owner-Developers (Pemberi Tugas)**: Companies that hire contractors but do not perform contracting work themselves (COVE V1 is built for the contractor wedge).
* **Mega-Enterprise State-Owned Enterprises (BUMN Karya)**: Require 12-month procurement cycles, extensive ERP replacements (SAP), and custom on-premise security certifications.
* **RAB / Estimating-Only Seekers**: Companies looking solely for cost estimation and unit price databases rather than progress-to-cash execution.
* **Unwilling to Share Workflow Data**: Companies unwilling to import even 1 project with anonymized claim values.

## 3. 100-Point Customer Qualification Scorecard

| # | Evaluation Dimension | Max Pts | Scoring Criteria |
| :-: | :--- | :-: | :--- |
| **1** | **Progress Billing Relevance** | 15 | • 15 pts = Monthly interim claims with opname & BAP<br>• 10 pts = Milestone termin (4–6 stages)<br>• 0 pts = 100% upfront or pure end-of-project payment |
| **2** | **Active Project Count** | 10 | • 10 pts = 3 to 8 active projects<br>• 7 pts = 2 active projects<br>• 3 pts = 1 active project<br>• 0 pts = 0 active projects currently running |
| **3** | **Commercial / QS Maturity** | 15 | • 15 pts = Dedicated QS/Commercial team that prepares monthly MC<br>• 10 pts = Project Engineer handles opname & MC<br>• 0 pts = No formal measurement process |
| **4** | **Finance Participation** | 10 | • 10 pts = Dedicated Finance Manager who issues invoices & tracks receipts<br>• 5 pts = Shared admin handles invoicing<br>• 0 pts = No formal invoicing tracking |
| **5** | **Workflow Fragmentation** | 10 | • 10 pts = Excel + WhatsApp + manual paper binders (high pain)<br>• 5 pts = Basic accounting software with manual spreadsheets<br>• 0 pts = Fully customized ERP system |
| **6** | **Financial Pain Severity** | 15 | • 15 pts = >Rp 500M currently stuck in uncertified volume or overdue invoices<br>• 10 pts = Moderate delay (15–30 days payment latency)<br>• 0 pts = No cash flow complaints |
| **7** | **Decision Maker Access** | 10 | • 10 pts = Direct contact with Owner / Managing Director / Commercial Director<br>• 5 pts = Contact with Senior PM<br>• 0 pts = Junior staff only with no executive sponsor |
| **8** | **Data Availability** | 5 | • 5 pts = Can provide 1 active project with 3–5 recent MC claims within 48h<br>• 2 pts = Data scattered, needs 1 week<br>• 0 pts = Data unavailable |
| **9** | **Willingness to Review** | 5 | • 5 pts = Agrees to 15-min weekly sync for 4 weeks<br>• 2 pts = Can only do ad-hoc text updates<br>• 0 pts = Refuses weekly review |
| **10** | **Strategic Fit & Referral Value** | 5 | • 5 pts = Well-respected mid-market contractor, potential case study<br>• 3 pts = Standard contractor<br>• 0 pts = Problematic relationship |
| | **TOTAL SCORE** | **100** | |
